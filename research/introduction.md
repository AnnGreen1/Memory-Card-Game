这是一个**记忆卡片配对游戏**项目，基于 React + Vite 构建。

## 项目概述

这是一款经典的记忆力训练游戏，玩家需要翻转卡片并找到配对的图案。

## 技术栈

- **框架**: React 19
- **构建工具**: Vite 7
- **语言**: JavaScript (ES6+)
- **样式**: CSS3

## 项目结构

```
Memory-Card-Game/
├── src/
│   ├── components/
│   │   ├── Card.jsx          # 卡片组件
│   │   ├── GameHeader.jsx    # 游戏头部（分数、步数、重置按钮）
│   │   └── WinMessage.jsx    # 胜利提示组件
│   ├── hooks/
│   │   └── useGameLogic.js   # 游戏逻辑 Hook
│   ├── App.jsx               # 主应用组件
│   ├── main.jsx              # 入口文件
│   └── index.css             # 全局样式
├── public/
└── package.json
```

## 游戏规则

1. 游戏包含 **16 张卡片**（8 对水果 emoji：🍎🍌🍇🍊🍓🥝🍑🍒）
2. 点击卡片翻转查看图案
3. 每次翻转两张卡片进行匹配
4. 匹配成功：卡片保持显示状态，得分 +1
5. 匹配失败：卡片自动翻回
6. 记录移动次数（每次翻两张算一步）
7. 所有卡片匹配完成后显示胜利信息

## 核心功能

- ✅ 卡片翻转动画效果
- ✅ 分数和步数统计
- ✅ 匹配成功高亮提示
- ✅ 胜利弹窗
- ✅ 新游戏重置功能
- ✅ 响应式设计（支持移动端）
